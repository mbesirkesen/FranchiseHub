# FranchiseHub Web API

Base: `http://127.0.0.1:8000` · Auth: `Authorization: Bearer <access_token>`

**Roller:** yalnızca `buyer` ve `franchise_owner` (admin kaldırıldı).

Liste yanıtları: `{ "items", "total", "page", "page_size", "total_pages" }`
